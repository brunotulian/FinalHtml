Este repositorio contiene el código fuente de un sitio web multipágina desarrollado en **HTML5**, diseñado para la presentación de un espacio recreativo, el cual incluye secciones de precios, contacto y galería de imágenes.

Estructura del Proyecto

El proyecto está organizado de la siguiente manera:

* **`index.html`**: Página principal del sitio. Contiene la bienvenida corporativa, contenido multimedia, un mapa interactivo de ubicación y la barra de navegación general.
* **`pages/contacto.html`**: Sección de contacto. Incluye un formulario completo de consultas (con campos de datos personales, selector de motivos y validaciones), además de un reproductor de audio integrado.
* **`pages/precios.html`**: Carta de precios y servicios. Muestra tablas detalladas con los costos de bebidas, comidas y reservas para diferentes categorías de Zonas VIP.
* **`pages/ustedes.html`**: Galería de fotos e identidad visual. Muestra momentos en la pista principal, zona VIP y patio del establecimiento[cite: 4].
* **`assets/`**: Carpeta contenedora de recursos multimedia.

Tecnologías Utilizadas

* **HTML5**: Estructuración semántica de las páginas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* **Elementos Multimedia**: Etiquetas nativas de HTML para reproducción de video 
* **Formularios HTML**: Campos interactivos con atributos de validación
